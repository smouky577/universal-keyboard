# Universal Keyboard

Пишеш **само на английска подредба**. Българските думи, написани на латиница,
стават на кирилица автоматично, щом натиснеш интервал или Enter. Английските думи остават същите.
След Enter новият ред започва начисто: програмата не помни на какъв език е бил предишният ред.
**Tab не преобразува** — например потребителското име при вход в сайт: пишеш `ivan`, натискаш Tab,
за да минеш в полето за парола, и `ivan` остава `ivan`, а не става `иван`.

```
zdravei, kak si? towa e mnogo hubawo   ->  здравей, как си? това е много хубаво
6te dojda utre, 4ovek                   ->  ще дойда утре, човек
hello my friend, how are you            ->  hello my friend, how are you
```

Разбира различни начини на писане: `sh`/`6` = ш, `ch`/`4` = ч, `sht`/`6t` = щ,
`w`/`v` = в, `y`/`a`/`u` = ъ, `q`/`ya`/`ia` = я, `j`/`zh` = ж,
`c` = ц или ч: програмата избира по речника (`cvete`, `cena` -> цвете, цена; `pricina`, `covek`, `obicam` -> причина, човек, обичам).
Ако думата с ч липсва в речника, `c` остава ц, тогава пиши `ch` или `4`.
Клавишите от фонетичната подредба също работят: `` ` `` = ч, `[` = ш, `]` = щ, `\` = ю
(със Shift: Ч, Ш, Щ, Ю).

## Сваляне

**[⬇ Свали Universal Keyboard (ZIP)](https://github.com/smouky577/universal-keyboard/releases/latest/download/universal-keyboard.zip)**

Разархивирай папката някъде (например в `Документи`) и пусни `start.bat`.
Нужен е [Python 3](https://www.python.org/downloads/) (при инсталиране отметни „Add Python to PATH“).
Други версии: [всички издания](https://github.com/smouky577/universal-keyboard/releases).

## Стартиране

```powershell
.\start.bat
```

В трея (до часовника) се появява синя икона **aБ**.
Програмата работи **само когато е избрана английската подредба**. На българската подредба не пипа нищо.

Не пипа нищо и:
- в **Command Prompt**, **PowerShell** и **Windows Terminal** (също pwsh, PowerShell ISE, WSL, Git Bash);
- в **полета за парола** (в браузъра, в Windows и в повечето програми) — там не преобразува и `Ctrl+Space` не работи.

| Клавиши | Действие |
|---|---|
| `Ctrl+Space` | Обръща последната дума (кирилица ↔ латиница) и **я запомня** за следващия път. Ако си по средата на дума, я прави на кирилица. |
| `Ctrl+Alt+K` | Пауза / пусни (може и с двоен клик на иконата) |

Десен клик на иконата: пауза, научени думи, изход.

## Автоматично стартиране с Windows

```powershell
powershell -ExecutionPolicy Bypass -File autostart.ps1
```
(махане: същото с `-Remove`)

## Как разпознава езика
1. Речници с чести думи (`uk/data/bg_words.txt`, `uk/data/en_words.txt`). Можеш да добавяш думи.
2. Статистика на буквените комбинации (n-gram) и характерни белези (`th`, `ing`, `6`, `q`, `-ite`, `-ata` ...).
3. Контекст: ако предишната дума е на български, двусмислените думи (`to`, `me`, `a`, `i`, `no`) също стават на български.
   Една английска дума в българско изречение не сменя контекста (`dobro idea, no` -> `добро idea, но`).
   След `.` `?` `!` започва ново изречение. Само главно `I` остава винаги английско (`I hope`).
4. Думите, които си поправил с `Ctrl+Space`, се пазят в `%APPDATA%\UniversalKeyboard\user_words.json`.

## Ограничения
- Не работи в програми, пуснати „като администратор“, освен ако и тя не е пусната така.
- Последната дума преди Tab не се преобразува. Ако искаш да е на кирилица, натисни `Ctrl+Space` преди Tab.
- Ако напишеш потребителско име на ръка и натиснеш Enter, то може да стане на кирилица. Полето за парола е защитено.
- Полетата за парола се разпознават чрез Windows UI Automation. Ако някоя програма не казва, че полето е за парола, натисни `Ctrl+Alt+K` (пауза), преди да пишеш паролата.
- Тест на разпознаването: `python test_engine.py`. Лог на решенията: `python universal_keyboard.pyw --debug` (думите се показват само в конзолата, не се записват във файл).

## Сигурност
- Програмата няма връзка с интернет и не отваря портове. Всичко става на компютъра ти.
- Написаните думи не се записват във файл. Те се пазят в паметта само докато пишеш думата (до 64 знака), после се трият.
- В поле за парола програмата не пази нищо, дори в паметта.
- На диска стоят само `%APPDATA%\UniversalKeyboard\user_words.json` (думите, които си обърнал с `Ctrl+Space`) и `log.txt` (кога е пусната и спряна, и грешки на програмата).
